# 3Zero Campus Club ISGT — Site officiel

## Ouvrir le site
Double-cliquez sur `index.html` pour le prévisualiser dans un navigateur.

## Modifier les informations
Toutes les variables principales sont regroupées au début de `script.js` :

- `QUESTIONNAIRE_URL = ""`
- `TIKTOK_URL = ""`
- `CLUB_EMAIL`
- `FACEBOOK_URL`
- `INSTAGRAM_URL`
- `LINKEDIN_URL`
- `PROJECT_POLE_MANAGER`
- `PROJECT_POLE_MANAGER_PHOTO`

Le logo officiel fourni est dans `assets/logo.jpeg`.

## Photos des membres
Les cartes du bureau utilisent volontairement des placeholders. Remplacez-les plus tard par les vraies photos sans inventer de portraits.

## Projets / événements / statistiques
Les contenus non fournis restent en placeholders. Aucun événement, projet ou chiffre réel n'a été inventé.
